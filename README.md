## 一、游戏简介

《黑誓：灵魂裂境》是一款运行于浏览器的**单屏竞技场动作肉鸽**。

你扮演一名踏入"裂境"的契约者，在一块固定大小的暗黑竞技场中迎击一波又一波的怪物。每场战斗结束获得经验、金币与装备，死亡或通关后带着**灵魂碎片**回到营地，兑换永久强化，再战。

**一局时长约 5～15 分钟**，目标是尽可能深地推进波次——共 **100 波 / 5 章**，每章末尾有专属首领。

### 设计取向

| 取向 | 说明 |
|---|---|
| 单屏竞技场 | 无地图探索、无相机跟随。所有战斗发生在一块 1280×720 的场地内，节奏紧凑 |
| 动作手感优先 | 走位、闪避无敌帧、技能 CD 管理、攻击朝向都由玩家实时掌控 |
| 构筑叠加 | 装备（5 部位）+ 天赋（每级 3 选 1）+ 技能强化（营地）+ 场景祭坛，四层叠加 |
| 永久成长 | 死亡不空手：灵魂碎片可兑换全职业永久属性与技能等级 |
| 每局不同 | 装备随机词条、天赋随机三选一、每日挑战随机词缀组合 |
| 打击感优先 | 命中停顿、镜头推近、屏幕震动、全屏演出、程序化音效——手感是网页单机的护城河 |
| 零外部依赖 | 全部美术与音效均为**程序化生成**（像素图由 Python 绘制、音效由 WebAudio 实时合成），项目内没有任何音频文件 |

## 二、运行方式

**直接双击 `index.html`** 即可开始游戏。

- 无需 Web 服务器、无需 Node、无需构建步骤
- 纯静态：`index.html` + `game.js` + `style.css` + `Assets/`
- 现代浏览器（Chrome / Edge / Firefox / Safari）均可运行

> **部署提示**：资源目录名为大写 `Assets/`，`game.js` 内的引用也已统一为大写。
> Windows 不区分大小写所以本地无感，但在 Linux / GitHub Pages 等区分大小写的环境下，若写小写 `assets/` 会全部 404，游戏只剩色块。当前版本已修复此问题，可直接部署。

## 四、核心循环

```
进入裂境 → 清波次 → 掉落金币/经验/装备
   ↓                        ↓
升级弹出三选一天赋     装备对比后换装或分解
   ↓                        ↓
使用场景祭坛/铁匠/商店强化自己
   ↓
每 20 波挑战章节首领（两阶段）
   ↓
死亡或通关 → 按击杀数与波次结算灵魂碎片
   ↓
营地兑换永久强化 → 下一局更强
```

**一局内的即时节奏**（单波循环）：

1. 波次开始，横幅提示波次类型（普通 / 精英 / 血月 / 首领）
2. 清光场上所有敌人
3. 进入 **3 秒休整**，倒计时显示下一波类型，可开商店、整理背包
4. 进入下一波

## 六、局内成长

### 6.1 等级与天赋

- 击杀获得经验：**普通怪 12 / 精英 45 / 首领 120**（血月波 ×1.5）
- 升级所需经验初始 **45**，每升一级需求 **×1.28**
- **每次升级弹出三选一天赋面板**（从本职业 6 个天赋中随机抽 3 个），选择后**本局永久生效**并暂停等待，选完立即恢复战斗

### 6.2 装备系统

**5 个装备部位**：武器 / 防具 / 鞋子 / 饰品 / 戒指

| 部位 | 主属性倾向 |
|---|---|
| 武器 | 攻击力 |
| 防具 | 护甲 |
| 鞋子 | 移动速度 |
| 饰品 | 最大生命 |
| 戒指 | 暴击率 |

**5 个品质等级**：

| 品质 | 颜色 | 属性倍率 |
|---|---|---|
| 普通 | 灰 | ×1.0 |
| 优秀 | 绿 | ×1.2 |
| 稀有 | 蓝 | ×1.5 |
| 史诗 | 紫 | ×1.9 |
| 传说 | 金 | ×2.5 |

**主属性公式**：设 `m = 品质倍率 × (1 + 装备等级 × 0.055)`

| 部位 | 主属性公式 |
|---|---|
| 武器 | 攻击力 `+ round(3 × m)` |
| 防具 | 护甲 `+ round(2 × m)` |
| 鞋子 | 移速 `+ 0.08 × m` |
| 饰品 | 最大生命 `+ round(10 × m)` |
| 戒指 | 暴击率 `+ 0.012 × m` |

**掉落与生成规则**：

- 装备等级 = `ceil(当前波次 / 4)`，属性随等级线性放大（每级 +5.5%）
- 品质由随机数 + 波次加成 + 掉落来源加成决定：**波次越深，高品质概率越高**
- 稀有及以上品质会额外获得 1～3 条**副属性**，副属性从职业专属池中抽取：
  - 骑士：生命 / 护甲 / 吸血 / 攻击
  - 猎人：攻速 / 暴击 / 穿透 / 攻击
  - 法师：攻击 / 法力回复 / 冷却缩减 / 范围
- 掉落概率：普通怪 6% / 精英 48% / 首领 95%（受难度、营地「猎宝者」升级、每日词缀影响）

**装备操作**：

- 拾取：靠近掉落物按 `E`
- **属性对比**：背包内每件装备都会显示与当前已装备物品的逐条属性差值，并给出**整体提升 / 偏向提升 / 属性取舍 / 整体下降**的判断
- **分解**：不需要的装备可分解为金币（价值 = 15 + 等级×4 + 品质序号×15）

### 6.3 局内商店（`B`）

| 商品 | 价格 | 效果 |
|---|---|---|
| 回血药水 | 45 金币 | 药水数量 +1 |
| 随机职业装备 | 120 金币 | 随机生成一件装备，**品质判定额外加权** |

## 七、关卡与波次

### 7.1 五章结构

共 **100 波**，每章 **20 波**：

| 章 | 名称 | 主色调 | 章节首领 | 章节怪物 |
|---|---|---|---|---|
| 1 | 荒废地牢 | 暗红棕 `#171416` | **狼王** | 腐化鼠人 |
| 2 | 幽暗森林 | 墨绿 `#111813` | **蝙蝠领主** | 饥渴狼人 |
| 3 | 诅咒沼泽 | 黄绿 `#15190f` | **女巫长老** | 沼泽尸鬼 |
| 4 | 巨人废墟 | 土黄 `#191713` | **独眼巨人首领** | 石肤巨人 |
| 5 | 黑暗神殿 | 暗紫 `#160f18` | **黑暗魔君** | 虚空信徒 |

### 7.2 波次类型

每章的 20 波中有固定的特殊波次：

| 波次位置 | 类型 | 说明 |
|---|---|---|
| 第 5、15 波 | **精英波** | 怪物数量减少约 35%，但前若干只为精英怪（生命 ×3.15、攻击 ×1.65） |
| 第 10 波 | **血月波** | 怪物攻击 +15%、移速 +18%，数量 +2；**本波奖励 ×1.5**（经验/金币/掉率），场景转为血红色调，必定生成宝箱 |
| 第 20 波 | **首领波** | 章节首领登场，两阶段战斗 |

其余为普通波。普通波中，每 3 波有 55% 概率随机生成一个场景互动装置。

### 7.3 怪物数量曲线

- 前 3 波：`2 + 波次`（2→5 只），且攻击力 ×0.8 —— **开局减负，避免刚上手就被打死**
- 第 4 波起：`4 + floor(波次 × 0.55) + 章节 × 2`

### 7.4 怪物基础成长

```
生命 = 34 × 1.05^(波次-1) × 难度倍率
攻击 =  7 × 1.03^(波次-1) × 难度倍率
移速 = 1.15 × 1.02^(波次-1)
```

### 8.1 怪物种类

不同章节抽取不同的怪物种类池，每种有独立的战斗 AI 与属性修正：

| 种类 | 生命 | 移速 | 攻击 | 行为 |
|---|---|---|---|---|

| **疾行者 runner** | ×0.72 | ×1.48 | ×0.86 | 高速追击；距离 80～300 时会**蓄力冲锋**（0.38 秒预警线，冲锋命中伤害 ×1.35） |
| **弓手 archer** | ×0.82 | ×0.93 | ×1.04 | 维持约 235px 的**理想射击距离**（太近后退、太远前进），射速 1.55 秒 |
| **施法者 caster** | ×0.90 | ×0.78 | ×1.15 | 维持 180～300px 距离，每 2.6 秒在**玩家脚下释放范围预警圈**（红色方框闪烁 0.72 秒后爆炸，125% 攻击力） |
| **坦克 tank** | ×1.55 | ×0.72 | ×1.12 | 缓慢逼近，自带 20% 最大生命的护盾 |

各章节怪物池：

| 章 | 可出现种类 |
|---|---|
| 1 | 壮汉、疾行者 |
| 2 | 疾行者、弓手、壮汉 |
| 3 | 施法者、壮汉、疾行者 |
| 4 | 坦克、壮汉、弓手 |
| 5 | 施法者、坦克、疾行者、弓手 |

### 8.2 护盾机制

精英怪、首领、坦克自带护盾：

- 护盾量 = 最大生命的 **38%（首领）/ 25%（精英）/ 20%（坦克）**
- 护盾会先于生命被消耗，**3 秒未受击后每秒回复 2.5% 最大护盾值**
- 破盾时有蓝色粒子反馈

> 打法提示：面对带盾敌人，持续输出比爆发更有效；中断输出 3 秒盾就会开始回。

### 8.3 精英词缀（噩梦及以上难度开启）

精英怪必带词缀，普通怪有 13% 概率携带。词缀会以**彩色描边 + 文字标签**显示在敌人头顶，方便识别应对：

| 词缀 | 颜色 | 效果 | 应对思路 |
|---|---|---|---|
| **加速** | 橙 | 移速 +25%（炼狱 +45%） | 别硬拼走位，用控制技能 |
| **吸血** | 红 | 每次攻击命中回复 2 倍攻击力的生命 | 需要爆发秒杀，持续消耗无效 |

五个章节首领，各自有专属立绘（每个 Boss 两阶段各一套 8 方向动画）与统一的三段式战斗逻辑。

### 9.1 首领属性


### 9.2 阶段机制

| 生命比例 | 阶段 | 表现 |
|---|---|---|
| 100% ~ 70% | 一阶段 | 常规攻击 |
| 70% ~ 35% | 二阶段 | **立绘切换为第二阶段形态**，触发全屏演出 |
| 35% ~ 0% | 三阶段（内部） | 攻击频率与弹幕数量进一步提升 |

**进入二阶段的瞬间**会触发：

- 首领硬直 0.55 秒 + 0.28 秒阶段无敌
- 屏幕震动 12
- 36 颗红金双色粒子爆发
- 一圈红色冲击波
- 顶部横幅提示「XXX 进入二阶段！」

### 9.3 首领招式

| 招式 | 触发 | 效果 |
|---|---|---|
| **扇形弹幕** | 每 `max(1.4, 3.7 − 阶段×0.65)` 秒 | 朝玩家方向发射 `阶段数` 发弹幕，扇形展开，每发 72% 攻击力，飞行速度随阶段提升 |
| **范围预警** | 与弹幕同时 | 在玩家当前位置生成红色方框预警（半径 58 + 阶段×12），0.78 秒后爆炸，伤害 90% + 阶段×16% |
| **召唤随从** | 每 `6.5 / 阶段` 秒 | 召唤 `(阶段 − 1)` 只普通怪加入战斗 |
| **近身爪击** | 贴身时，0.72 秒一次 | 带爪痕特效的近战攻击 |

> 打法提示：红色方框是**预警圈**，出现后立刻离开；弹幕数量随阶段增加，三阶段时要优先清理被召唤的小怪。

## 十五、画面与美术表现

### 15.1 像素美术规格

| 怪物 | 48 × 48（第 4 章 64 × 64） | 8 行 × N 帧 | 5 种 × 5 动作 = 25 张 |
| 首领 | 96 × 96（第 4、5 章 128 × 128） | 每阶段一张，8 行 × 6 帧 | 5 Boss × 2 阶段 = 10 张 |

| 装备图标 | 32 × 32 | — | 3 职业 × 5 部位 = 15 张 |

### 15.3 场景构成

背景在每帧绘制，由多层叠加而成（刻意不使用规则网格，避免"表格地板"观感）：

1. **4px 像素颗粒层**：哈希噪声驱动的色块，营造粗糙石地质感（此前为 8px，颗粒粗到能看出"格子"）
2. **2px 细斑层**：稀疏的高频细斑，进一步打散大色块，消除网格感
3. **32px 地面结构层**：不规则大块石板与裂纹线条
4. **30 条地面裂纹折线**：两段折线 + 哈希抖动，位置稳定不闪烁
5. **46 块碎石**：小多边形，带受光面
6. **章节装饰**：从地形图集中稀疏抽取 10 个 32px tile，放大到 48px 摆放
7. **地表细节**：按章节生成血迹 / 草丛 / 骸骨（哈希定位，位置稳定不闪烁）
8. **符文魔法阵**：第 1、5 章在场地中央绘制金色双环法阵（外环实线、内环虚线、8 枚符文点）
9. **墙边火把**：4 座，带火焰跳动与光晕 —— 同时是**动态光源**
10. **边缘暗墙**：上下边缘的不规则暗色带，强化"封闭房间"感
11. **径向渐变压暗**：中心亮、四周沉入黑暗（收尾强度 0.66，此前 0.82 过暗）

### 15.4 动态光照系统

这是画面氛围的核心。实现方式：

- 维护一张 **640 × 360** 的低分辨率光照图（主画布的 1/2，此前为 1/4）
- 先用章节环境光色铺底，再以 `lighter` 混合模式叠加各光源的径向渐变
- 最后以 **`multiply` 模式**合成回主画布 —— 光源处提亮，无光处沉入环境暗色

### 15.6 技能与特效表现

所有特效均为程序化 Canvas 绘制，**不使用贴图**。核心设计原则是「多层结构」：一个特效至少包含 *扩散体 + 主体 + 高光核 + 碎屑* 四层，而不是早期版本的一根粗线。

#### 15.6.1 绘制管线（关键架构）

特效被拆成两条绘制通道，这是本轮画质提升的地基：

```
drawWorld()     → 地面类特效（预警圈 / 危险区 / 箭雨落点 / 陷阱 / 蓄力线）+ 敌人 + 玩家
drawLighting()  → 光照层（multiply 合成，会压暗一切已绘制内容）
drawFxLayer()   → 发光类特效 + 箭雨箭矢 + 冰冻冰壳 + 弹道 + 粒子 + 飘字
```

早期所有特效都在光照层**之前**画，于是无论用多少层高光，最后都会被 `multiply` 压成一团暗色 —— 这是「特效看起来又粗又假」的真正原因。现在刀光、冰山、陨石、冲击环、命中火花、箭矢全部移到光照之后，才真正"发光"。

判定归属的常量：

```js
const GROUND_FX = { telegraph:1, danger:1, rain:1, trap:1, charge:1, meteorMark:1 };
```

#### 15.6.2 精细绘制原语

替代原先生硬的 `lineWidth:5` 圆弧 + 8×8 方块，新增一层几何原语（`game.js` 顶部）：

| 原语 | 作用 |
|---|---|
| `ringSector` | 双色径向渐变扇面 —— 冲击环 / 光斑的基底 |
| `crescentSector` | 月牙光带（内圈透明 → 中段最亮 → 外缘锐利），读起来才像"刀锋扫过"而非"扇形色块" |
| `cometSector` | 沿角度渐隐的扫掠带，把若干 `crescentSector` 按 `f0^2.2` 叠成**彗尾** —— 刀光与旋风的灵魂 |
| `glowSpot` | 径向辉光点（顶部 / 中段 / 边缘三段透明度） |
| `polyFill` / `polyStroke` | 非圆形轮廓（冰锥、箭簇、爪痕、符文） |
| `frand(seed)` | 确定性伪随机 —— 特效每帧稳定，不会闪烁抖动 |
| `easeOut` / `easeIn` / `easeInOut` | 缓动，让扩散"先快后慢"而不是线性 |

#### 15.6.3 骑士 · 三段连击与真剑

普攻不再是「一道白色划痕」，而是**挥砍 → 横扫 → 突刺**三段连击，0.68 秒内续招则推进段数：

```js
const KNIGHT_COMBO = [
  { type:'swing',  dmg:.92, range:80, arc:1.6, dur:.20, lunge:0,  shake:3, label:'挥砍' },
  { type:'sweep',  dmg:1.06,range:88, arc:2.5, dur:.24, lunge:7,  shake:4, label:'横扫' },
  { type:'thrust', dmg:1.55,range:96, arc:.70,dur:.26, lunge:24, shake:6, label:'突刺' }
];
```

- **武器由角色精灵图提供**：骑士长剑画在 `Assets/characters/knight/*.png` 里（生成器 `draw_knight()` 的「右臂 + 剑」段），随 8 方向帧跟随鼠标朝向，攻击帧自带大幅度挥剑。
- **身体有重量感**：挥砍瞬间整体绕脚底旋转 `sin(q·π)·0.12` 前倾扭转，收招回正。
- **刀光**（`drawSwingFx`）：彗尾状月牙（`cometSector`）+ 外缘金边 + 白热核 + 7 条放射速度线 + 刃尖火花；突刺则是渐变枪影 + 尖端双层冲击环 + 纵向速度线。
- **一件武器原则**：三个职业的武器（骑士剑 / 猎人弓 / 法师法杖）**只由精灵图提供**，代码不再叠加第二把。早期版本额外用 `drawBladeShape()` / `drawHeroWeapon()` 画了一套跟随鼠标的武器，与贴图那把同时出现 —— 视觉上就是「骑士有两把剑」，已于 v11 移除。

#### 15.6.4 法师 · 冰山冻怪与陨石天降

| 特效 | 演出结构 |
|---|---|
| **寒霜爆裂**（0.88s） | 起手辉光 → 双层冰环扩散 → **9 根环绕冰锥 + 1 根中央主冰锥**（三面明暗 + 白色棱边，模拟晶体折射）→ 0.60s 处炸裂，12 片冰屑飞散 + 冲击环 |
| **冻结状态** | 被冻结的敌人套上 `drawFrozenOverlays()` 多边形冰壳（带棱面高光），且**完全停止移动** |
| **陨石天降**（三段链） | `meteorMark`(0.60s 地面灼烧预警：双层环 + 旋转虚线 + 十字准星) → `meteorFall`(0.32s 天降：15 段渐缩拖尾 + 7 条尾焰火舌 + 三层核心) → `meteorImpact`(0.9s：冲击坑 + 9 条三段折线放射火舌 + 15 团土石飞溅 + 震屏 15 + 顿帧) |

落地命中会附加 4 秒灼烧（`n.burn`），火舌与土石的飞行高度用 `easeIn` 计算，读起来是"砸下来"而不是"贴上去"。

#### 15.6.6 性能

同一敌量对照（29 敌人，headless Edge + 软件光栅）：无特效 55 FPS；额外再叠加 2 个常驻箭雨区 + 常驻旋风 + 危险区 + 冲击波（远超实际战斗的最坏情况）42–48 FPS。

为控制开销做了两处取舍：箭矢数量 18 → 13 且用椭圆填充替代逐箭径向渐变；旋风彗尾分段 10 → 7。所有渐变均**逐帧即时创建、不缓存**，因为特效存活时间普遍 < 1 秒，缓存反而更亏。

### 15.7 角色表现细节

- **脚下职业光晕**：按职业着色的径向光（骑士金 / 猎人蓝 / 法师紫），让主角从暗色地面中"浮"出来
- **接地阴影 + 金色脚环**：强化角色在场景中的存在感
- **动作状态机**：受击 → 技能 → 攻击 → 行走 → 待机，按优先级切换动画
- **待机呼吸**：上下 1.5px 浮动；**行走弹跳**：随步频上下 2px
- **无敌闪烁**：受击后 0.12 秒内以半透明白色闪烁
- **冰霜减速指示**：被减速时周身出现冰蓝描边方框

### 15.8 屏幕后处理

通过 CSS 叠加两层全屏效果（可在设置中关闭扫描线）：

- **径向暗角**：中心透明 → 边缘 72% 黑色，`multiply` 混合，营造聚光灯式聚焦
- **扫描线**：每 3px 一条 1px 的极淡骨白横线，模拟 CRT 显像管质感

### 15.9 界面视觉风格

DOM 面板统一采用**暗黑金属描金**风格：

- 面板：深灰渐变底 + 4px 灰褐描边 + 1px 金色内描边 + **八边形切角**（`clip-path`）+ 厚重投影
- 主菜单：标题上方 ☩ 符号、底部金色渐变横线、顶部径向暗红光晕
- 按钮：无圆角、2px 描边、内嵌黑边、硬投影；悬停时反转为金底黑字，按下时整体位移 1px
- 职业卡：顶部径向金光 + 角色立绘 + 职业徽记 + 属性行 + 特性列表
- 品质色阶：普通灰 / 优秀绿 / 稀有蓝 / 史诗紫 / 传说金，贯穿装备名、图标边框、掉落光柱
- 字体：微软雅黑为主（中文），等宽字体用于数值与 HUD
- 断点：800px 与 520px 两档响应式

## 十七、设置与性能

### 设置项

| 设置 | 选项 | 说明 |
|---|---|---|
| 音效音量 | 0 ~ 1 滑块 | 控制全部程序化音效的主音量 |
| 画质 | 高 / 中 / 低 | 控制粒子预算与规模、光照采样密度 |
| 动态光照与氛围 | 开关 | 关闭后跳过整个光照合成，低配设备收益明显 |
| 屏幕震动 | 开关 | 关闭后取消所有震屏，同时关闭击杀镜头推近 |
| 伤害数字 | 开关 | 关闭后不再生成飘字 |
| 扫描线特效 | 开关 | 关闭 CRT 扫描线 |
| 整数倍缩放 | 开关 | **默认开启**。开启时画布按整数倍放大（像素完全锐利）；关闭则拉伸铺满窗口 |
| 导出 / 导入存档 | 按钮 | 导出为 `.json` 文件（同时复制到剪贴板）；导入会覆盖当前存档 |

所有设置即时生效并自动保存。

### 渲染架构

- Canvas 2D，固定 **1280 × 720** 逻辑分辨率
- **静态背景离屏烘焙**：背景（像素颗粒层、地面结构、章节装饰、地表细节、符文法阵、火把、边缘暗墙、渐变压暗）在进入新章节时烘焙到一张离屏画布，之后每帧只做一次 `drawImage`。原先这些内容每帧要执行约 **16000 次 `fillRect`**
- **整数倍缩放**：按窗口尺寸计算 1x / 2x / 3x… 整数倍，画布居中显示，保证像素格大小完全一致。窗口小于 1280×720 时退回铺满模式
- 主循环：`requestAnimationFrame`，单帧 dt 上限 0.033 秒（掉帧时不会穿模）
- 光照图离屏缓存（1280×720 的 1/4 = 320 × 180），避免全分辨率合成
- 无 WebGL、无 Worker、无外部依赖、无外部音频文件

### 性能表现

在无 GPU 加速的环境下实测（同一台机器，同一场景）：

| 指标 | 优化前 | 优化后 | 变化 |
|---|---|---|---|
| 每秒钟 JS 执行耗时 | 163.7 ms | 44.8 ms | **−72.6%** |
| 每秒钟主线程繁忙时间 | 1003.9 ms | 829.8 ms | −17.3% |

> 用带 GPU 加速的真实浏览器运行时，绘制开销主要在光栅化环节，收益同样体现在帧时间上。
> 按 `F3` 可实时查看 FPS 与实体数。

低配设备建议：关闭动态光照 + 扫描线，画质调至「中」或「低」。

### V10 · 画质与特效升级

**根因诊断：不是像素分辨率问题，是绘制管线问题。** 原实现所有特效都画在 `drawLighting()` 之前，而光照层用 `multiply` 合成 —— 画多少层高光都会被压成一坨暗色。

**解法：拆成两条绘制通道**

```text
drawWorld()     → 地面类特效（预警/危险区/箭雨落点/陷阱/蓄力线）+ 敌人 + 玩家
drawLighting()  → 光照层（multiply，会压暗其后一切）
drawFxLayer()   → 发光特效 + 箭雨箭矢 + 冰壳 + 弹道 + 粒子 + 飘字
```

**新增精细绘制原语**：`crescentSector`（月牙光带）、`cometSector`（彗尾，按 `f0^2.2` 渐隐叠加）、`ringSector`、`glowSpot`、`polyFill` / `polyStroke`、`frand`（确定性伪随机，避免逐帧闪烁）+ 三种缓动函数。

**骑士：三段连击**

`挥砍 → 横扫 → 突刺`，0.68 秒内续招推进段数。挥砍瞬间身体绕脚底前倾扭转 `sin(q·π)·0.12`，收招回正。

**法师：冰山冻怪 + 火球降世**

- 寒霜爆裂延长到 0.88s：9 根环绕冰锥 + 中央主冰锥（三面明暗 + 白棱边模拟晶体折射），0.60s 炸裂飞屑。
- 被冻结的敌人套上多边形冰壳且**完全停止移动**。
- 陨石改为三段链：`meteorMark` 地面灼烧预警（0.60s）→ `meteorFall` 天降拖尾（0.32s，15 段渐缩尾迹 + 7 条尾焰）→ `meteorImpact` 冲击坑 + 9 条三段折线放射火舌 + 15 团土石 + 震屏 15 + 顿帧。

**其余技能全量重绘**：冲锋斩（彗尾扫掠 + 地面裂痕）、裁决旋风（3 片 120° 旋转刀光各带彗尾）、箭雨（地面软光斑 + 13 支循环下落的箭，含箭杆/尾羽/箭簇/落地尘环）、冰霜陷阱（旋转符文 + 双面冰晶 + 触发炸 8 根冰刺）、危险区（充能填充 + 斜纹网 + 四角括号）、落点指示器（12 刻度 + 顺时针充能弧）、施法聚气（8 枚由外向内收束的符文）、冲击波（四层同心环）、命中火花、闪避残影。

**场景纹理与光照精度**：地面颗粒 8px → 4px 并加 2px 细斑；新增 30 条裂纹折线 + 46 块碎石；光照图 320×180 → **640×360**；环境光提亮 40%；暗角 .82 → .66；粒子改三层（外发光 + 亮核 + 白点）。

**顺带修掉的真 bug**：陨石改三段链后，光照层仍匹配旧的 `meteor` 类型 —— 陨石已彻底不产生光照（死代码）。已改为匹配三种新类型，并给施法/冲锋斩/旋风/陷阱/危险区补上光源。

**性能取舍**：箭矢 18 → 13 且用椭圆填充替代逐箭径向渐变；旋风彗尾分段 10 → 7。所有渐变逐帧即时创建**不缓存**（特效存活普遍 < 1 秒，缓存反而更亏）。

**实测**：常规战斗 59 FPS；最坏情况（27 敌人 + 常驻箭雨/旋风/危险区 + 180 粒子）49 FPS；无特效对照 55 FPS。

### V11 · 武器重复修复

**现象**：骑士看起来有两把剑。

**根因**：三个职业的**精灵图本身就带武器**（生成器里骑士画了 25px 长剑 + 金护手 + 剑柄，猎人弓、法师法杖同理），而 V10 又在 `game.js` 里额外画了一套跟随鼠标的武器 —— 同屏两件同类武器，且位置角度都不重合，骑士是两条不重合的直线所以最扎眼。

**修复**：采用「一件武器原则」—— 武器只由精灵图提供，代码不再叠加第二把。删除 `drawPlayer()` 里的武器调用，以及 `drawBladeShape()` / `drawKnightSword()` / `drawHeroWeapon()` 三个函数（53 行）；`game.js` 1257 → **1202 行**。

**保留不动**：三段连击数据结构、`drawSwingFx()` 的彗尾月牙刀光（在光照层之后绘制，本就是全屏最亮的部分）、身体前倾扭转。挥砍的视觉主体是刀光，不是那把代码剑。

**验证**（同场景像素度量，修复前 → 修复后）

| 指标 | 数值 | 读法 |
|---|---|---|
| 亮银像素（刃面） | 741 → **437（−41%）** | 56px 的代码剑确实消失 |
| 金色像素（护手/剑柄） | 619 → 593（−4%） | 贴图剑金护手仍在 |
| 边缘密度 | 1931 → 1850 | 画面没变糊 |
| 帧率 | 31.4 → **43.6 FPS（+39%）** | 少画一整套多层多边形 + 径向辉光的白赚 |

三职业各自回归 `errs=0`（骑士 576/437/593、法师 648/197/484、猎人 635/199/641）。对照截图见 `preview_weapon_fix/`（4 张，均为关光照视图，便于看清角色本体）。

> **后续若要调整武器外观**：贴图剑长 25px、方向精度 45°（8 方向帧）。希望剑更长/更亮，正确做法是改**贴图生成器** `draw_knight()` 里的 `sword_len` 与配色，**不要**再加一层代码剑 —— 那样又会变回两把。猎人弓 / 法师法杖同理。

### V12 · 关卡制与海克斯构筑

**为什么改**：V11 之前是「清空后 3 秒自动开下一波」，玩家没有"打完一关"的实感，也没有局内构筑方向 —— 天赋是升级就给、装备靠掉落，一局的强度曲线基本由运气决定。

#### 一、波次制 → 固定数量关卡制

| 项 | 规则 |
|---|---|
| 每关总数 | `round(B[章] + K[章] × (关内序-1))`，`B=[6,11,15,19,23]`、`K=[.55,.62,.70,.78,.86]` |
| 采样 | 第 1 关 6 只 / 第 50 关 21 只 / 第 95 关 35 只；第 100 关 `1 首领 + 8 精英` |
| 精英关 | 只**替换** 25% 为精英，不增加总数（严格满足"每关固定数量"） |
| 血月关 | 总数不变，敌人 +15% 攻 / +18% 速，金币经验 ×1.5 |
| 涌入方式 | 恒 4 批、批间隔 0.85s、批内错峰 0.12s；同屏 >22 挂起，降到 ≤16 再放 |

**清空判定**用计数器而不是 `enemies.length===0`：`remain`（非召唤击杀递减）+ `pendingSpawns` + `spawnQueue` 三者同时归零才结算。分裂词缀的产物 `remain += 2` 并打断结算回 combat；首领召唤物 `summoned=true` 只受上限 6 约束，不参与判定。

**状态机**：`combat → clearing(0.60s) → cleared_show(1.68s / 首领 3.20s) → portal_grow(0.90s) → portal_ready → portal_enter(0.35s)`。
演出可按 WASD/空格/E/左键跳过（跳过只清零 cleared_show，生长仍跑满 0.90s）；首领关同样可跳。第 100 关保留演出但金字改「裂境闭合」，不生成通道。

#### 二、通关通道

| 形态 | 章节 | 进入半径 |
|---|---|---|
| 地下通道 `trapdoor` | 第 1–2 章（1–40） | 46px |
| 石门 `stone_door` | 第 3–4 章（41–80） | 46px |
| 裂境裂隙 `rift` | 第 5 章（81–100）+ 首领关 20/40/60/80 | 46px |

锚点取**最后一击坐标**，别 HUD 面板（小地图 / 角色面板 / 技能托盘 / 首领条）以 24px 步长向场地中心回退。绘制拆前后两层：坑底/门板在 `drawWorld`，门柱/坑沿在 `drawPlayer` 之后，角色走进门才有纵深。

提示只有两个元件，按距离互斥：`>400px` 只画屏幕边缘金色箭头；`46–400px` 只画本体脉冲；`≤46px` 加 `[E]`。主路径是 E 键，12s 挂机才自动进入（`save.settings.autoPortal` 可关）。

#### 三、海克斯裂境馈赠（每 3 关一次，共 33 次）

42 条增益分四档（白银 15 / 黄金 12 / 棱彩 9 / 禁忌 6），其中 **13 条是机制型**而非数值：雷链、尸爆、技能回响、闪避残影、连击齐射、分裂弹、环绕符文、风暴之心、霜爆新星、陨星标记、殉道反甲、时之沙漏、血契。

- 同一张卡可叠到 5 层（棱彩 3 / 禁忌 2），但**轮转冷却 3 次事件**，5 层最早约第 39 关
- 主导系保底第 1 张；每 5 次事件若主导系 ≥4 层，保底给该系未持有的机制卡
- 禁忌卡第 41 关起才进池，效果强但带代价（如攻击 ×1.25 / 生命 ×0.88）
- 数值护栏在 `recalcHex()` 统一夹：攻击乘区 ×2.60、生命 ×2.20、攻速 +0.90、暴击 0.90、冷却 0.45

**关键实现约束**：海克斯乘区**不写进 `p.atk`**，而是独立的 `hexLayers` 在 `damageEnemy` / `hurtPlayer` 结算。因为铁匠每级把装备属性 ×1.18 且可叠 8 级，若与海克斯复利相乘会绕过 ×2.60 夹紧，让单件装备接管全局。

#### 四、性能与画质

10 项结构性优化：粒子对象池 + 前向写指针压缩（消除每帧 `new`/`splice`）、屏幕外裁剪、热路径 `hypot` → 平方距离、光照图按画质 640×360 / 320×180 / 160×90（low 隔帧 + 关柔化）、HUD 静态层离屏烘焙、`stat()`/`waveInfo()` 脏标记缓存、去掉每帧 `filter`/`sort`、`glowSpot` 早退、小粒子跳过外晕。

画质提升全部走**离屏**，不加每帧成本：背景烘焙加 120 颗细石粒 + 7 处章节色微光斑；通道发光层单独走 `drawFxLayer`（不受光照 multiply 压暗）。

#### 五、技能特效

补上原先**完全没有特效**的两个技能：骑士「圣光护体」→ 六棱壳 + 十字光芒（禁圆形，避免与盾类混淆）；法师「法力涌泉」→ 柱状光带 + 8 枚环形符文。新增 `game.decals[]` 地面残留层（上限 8/5/2），陨石灼痕 / 旋风刮痕 / 寒霜霜环 / 箭雨尘土共用。主发光体统一「白热核 + 双层描边」。
