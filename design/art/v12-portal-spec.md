# V12 · 关卡结算通道 视觉规格
> 项目：《黑誓：灵魂裂境》V12｜Canvas 2D 1280×720｜`imageSmoothingEnabled=false`｜零贴图全程序化
> 上游 `design/gdd/level-flow.md`｜下游 `game.js`。**时间=秒，尺寸=逻辑像素，颜色=#RRGGBB，全部可直接编码。**
## 0 全局约定
| 项 | 规范 |
|---|---|
| 锚点 | `anchor=(x,y)` = 地面接触点（底边中心）。一律 `translate(round(x),round(y))`，向上为负 y |
| 外框 | 地下通道 **112×88**｜石门 **120×140**｜裂境裂隙 **128×150** |
| 进入判定 | 圆心距 `≤46px`（沿用现有 props 的 `dist(p,pr)<46` 手感）。**必须按 E**，不做踏入自动进入 |
| 生成位置 | 最后一击位置 clamp 到 `x∈[160,W-160]`、`y∈[170,H-120]`（y 下限 170：裂隙 150 高向上生长，150 会顶破画面上沿，且要给首领血条让位）；与未使用 props 距离 `<70` 时沿 x 偏移 `±90` |
| 形态映射 | 1-2 章 地下通道｜3-4 章 石门｜5 章 **+ 20/40/60/80 首领关** 裂境裂隙。**第 100 关不生成通道对象**：① 0.60 迟滞 → ② 改 **3.20s 纯过场**（去饱和 + 金字「**裂境闭合**」，**无副行、无箭头、无光圈、无 `[E]`**）→ 直接 `endRun(true)`，**不进入 ③ 生长** |
| 双通道归属 | 地面/结构 → `drawWorld()`（光照**前**，被 multiply 压暗＝正确）；发光 → `drawFxLayer()`（**不受压暗**）。类型常量 `PORTAL_FX={portalBase:1}` 并进 `GROUND_FX`，`portalGlow` 不入表 → 自动走 FxLayer |
| 绘制层级 | **拆前后两层**：后景（坑底/台阶/门板/撕裂底）在 `game.props` 之前、`game.enemies` 之前画；**前景柱**（石门左右门柱内侧各 8px、通道左右坑沿内侧各 6px）在 `drawPlayer()` 之后单独画一次 → 角色走进门时被门框前柱压住，有"进门"纵深。前景柱出现时机**只跟 ③ 生长结束走，不跟"玩家按了跳过"走**（否则会出现"门还没长完前柱已压住角色"的穿帮）；③ 之前一律不画 |
| 确定性 | 随机一律 `frand(frame*3.7+anchor.x*.01)`。**禁用 `Math.random()`**，否则逐帧闪烁 |
| 冻结 | `game.paused` 或 `portalLocked` 为真时，把相位冻结在暂停的那一帧（勿把 `performance.now()` 直接当相位） |

## 6 「可进入」状态
| 元素 | 参数 |
|---|---|
| 距离档位（**互斥，逐帧判定，同帧只成立一档**） | **元件共 2 个**：本体脉冲光圈、`offscreenArrow`。`>400px`：只画 `offscreenArrow`（本体脉冲与 `[E]` 都不画）｜`46~400px`：只画本体脉冲（无箭头、无 `[E]`）｜`≤46px`：本体脉冲 + `[E] 踏入通道`。**地面小箭头（`groundChevron`）已裁决取消**——46px 内会和 `[E]` 文字叠压、400px 外与边缘箭头重复提示，本体脉冲已是"这里能进"的最强信号，**不要再加第三元件** |
| 本体脉冲光圈 | `portal_ready` 起常显；**`portal_grow` 期间不画**（③ 由灰罩 + 相位冻结表示"还没长完"），**模态面板（海克斯/背包/商店）打开期间也不画**。基础参数：地面 `ellipse` rx46 ry16，2px `#ffd700`，α `0.55+0.25*sin(2πt/1.2)`；外环 rx56 ry20，1px α.22。**按距离档参数插值（同一对象、同一绘制函数，只做一次 `distTier` 判定）**：`46~400px` 档 rx `46→52`、α 峰值 `.55→.70`、周期 `1.2→0.9s`、外环 α `.22→.34`；`≤46px` 档回基础值；`>400px` 档不画。本体同步增强：通道地气 α ×1.4｜石门光柱峰值 +0.12｜裂隙呼吸周期缩至 2.0s |
| 屏幕边缘指示 `offscreenArrow` | 条件 `dist(player,anchor) > 400` 且 `portal_ready`，**逐帧判定**；**任何模态面板（海克斯/背包/商店）打开期间隐藏**（不只是冻结 —— 暂停时箭头还在闪会被当成"走这边"的误导）。屏幕四边内侧 24px 处，沿玩家→anchor 取与边框交点，画 1 枚金色大箭头（`polyFill` 18×14，`#ffd700` α`0.5+0.3*sin(2πt/0.8)`）+ `glowSpot` r=44 rgb`255,210,100` α.24。与本体脉冲是**两个独立元件，不要复用同一个对象或同一个函数** |
| 提示框 | 复用 `panelBox(W/2-110,H-146,220,32)`；文字 `[ E ] 进入下一关`，`bold 12px monospace` `#ffd700` @(W/2,H-124)（与现有 `PROP_PROMPT` 完全同款）。**常显不切换**：面板关闭当帧立刻可按 E，不加"重新激活"动画，否则玩家会误以为要先走开 |
| 防呆 | **三个条件同时满足才自动进入**：① 玩家在 46px 内（**离开则计时清零，回来重新计 12s**）；② 连续 12s 无任何有效输入（`WASD/空格/E/鼠标点击` 任一即重置）；③ **计时器只在 `!game.paused` 时累加**，面板暂停期间冻结、关闭后从 0 重计。`save.settings.autoPortal!==false` 时启用，末 3s 提示框追加 `(3)` |
| portalLocked | **③ 生长期间**：光圈/外环/箭头/`[E]` 全部不画、通道叠 α.35 灰罩、**脉冲相位冻结**（语义＝"还没长完"）。**④ 且模态面板已开**：脉冲与箭头都不画（面板遮着，画了也是浪费），`[E]` 输入被模态吃掉；面板关闭当帧立刻恢复绘制并可按 E，**不加"重新激活"动画**。背包/商店同规则 |
