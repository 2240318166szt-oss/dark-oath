# 海克斯裂境增益池 · V12

> 归属：文策渊（策划）｜版本 V12｜状态：待用户拍板｜定位：关卡制下玩家的**主要构筑来源**（天赋=被动成长，海克斯=主动构筑）
## 1. 设计支柱
构筑而非数值（13 条机制型，效果是新行为而非加成）｜三选一的取舍（4 档稀有度 × 5 层叠加 × 禁忌带代价）｜可读（33 次事件 / 42 条池 / 单条 5 层封顶 / 全局夹紧）
## 2. 核心规则（可直接编码）

| 项 | 规则 |
|---|---|
| 触发时机 | 关卡 n 满足 `n % 3 === 0` 时，**关卡结算后、通道生成前**弹出三选一；游戏暂停 |
| 事件总数 | 1..100 中 3 的倍数 = 33 次（含第 60 关：首领战 → 章节结算 → 海克斯，顺序见 level-flow.md §3） |
| 抽卡 | 抽 3 张，同事件内不重复；按 §6 权重分档后档内均匀抽 |
| 主导系保底 | 3 张中**第 1 张**强制来自「主导系」（累计层数最高的系，并列取先达成者） |
| 系核心保底 | 每 5 次事件，若主导系累计 ≥4 层且该系还有未持有的 ★机制型，则 3 张中强制含 1 张 |
| 满层处理 | 已满层的条目**移出卡池**；若 3 张全为空则免费重掷（不计次数，最多 2 次） |
| 轮转冷却 | 同一条增益被选取后，**需间隔 3 次事件**才可能再次出现（即 5 层最早在事件 1/4/7/10/13，约第 39 关） |
| 叠加方式 | `linear` 数值相加｜`mult` 乘区相乘｜`trigger` 触发参数（跳数/枚数/概率）成长 |

## 8. 数值护栏（防第 30 关崩塌）

**全局硬夹紧**（超出的层数被丢弃，不报错）：

| 项 | 上限 |
|---|---|
| 海克斯提供的攻击乘区合计 | ×2.60 |
| 最大生命乘区合计 | ×2.20 |
| atkSpeed 加值合计 | +0.90（等效间隔 ×0.53） |
| 暴击率 / 暴击伤害 | 0.90 / 4.20 |
| 冷却缩减合计 | 0.45 |
| lifesteal 有效值 | 0.30 |
| 单帧机制触发次数 | ≤3（防尸爆→连锁→再尸爆的递归） |
| 机制型 ICD 下限 | 0.15s |

**关卡许可乘区（含轮转冷却 3 次事件的约束）**：

| 关卡 | 海克斯次数 | 单条最大层数 | 攻击乘区最坏值 | 设计区间 |
|---|---|---|---|---|
| 15 | 5 | 2 | ×1.25 | 1.15–1.35 |
| 30 | 10 | 4 | ×1.83（两条各 4/3 层） | 1.30–1.90 |
| 60 | 20 | 5+5 | ×2.31 | 1.80–2.40 |
| 100 | 33 | — | ×2.60（被夹紧） | 2.30–2.60 |

第 30 关校验：最坏路径是把 10 次选择全部砸进攻击（sv_atk 4 层 ×1.32 + gd_atk 3 层 ×1.39 = ×1.83），此时该玩家 8 次选择全无防御，精英一击可带走 40% 生命 —— 这是**有代价的极端构筑**，不是崩塌。第 30 关普通怪 HP = `34×1.05^29 ≈ 140`，×1.83 后单体 TTK 约 0.6s，可接受。
