# 关卡流程与节奏 · V12

> 归属：文策渊（策划）｜版本 V12｜状态：待拍板｜术语：**关** n=1..100｜**章** ch=floor((n-1)/20)，0..4｜**关内序** stage=(n-1)%20+1，1..20

## 1. 每关固定怪物数量

**公式**（进关只算一次，之后不再补刷）：`ch=floor((n-1)/20)`，`stage=(n-1)%20+1`，`regular=round(B[ch]+K[ch]×(stage-1))`，`B=[6,11,15,19,23]`，`K=[0.55,0.62,0.70,0.78,0.86]`

| 关型 | 总数规则 |
|---|---|
| 普通关 | `regular` |
| 精英关（stage 5 / 15） | `regular`，**不增不减**；其中 `eliteN = clamp(round(regular*0.25), 2, 6)` 只替换为精英 |
| 血月关（stage 10） | `regular`，只加 +15% 攻 / +18% 速，金币经验 ×1.5 |
| 章节首领关（20/40/60/80） | `1 + min(round(regular*0.35), 12)`（首领 + 护卫） |
| 第 100 关 | `1 + 8`（终局首领 + 8 只固定精英编队） |

## 2. 怪物构成与分批涌入

| 章 | kind 池 | 占比（按生成顺序轮转取样，余数补 brute） |
|---|---|---|
| 0 荒废地牢 | brute / runner | 60 / 40 |
| 1 幽暗森林 | runner / archer / brute | 40 / 30 / 30 |
| 2 诅咒沼泽 | caster / brute / runner | 30 / 35 / 35 |
| 3 巨人废墟 | tank / brute / archer | 25 / 40 / 35 |
| 4 黑暗神殿 | caster / tank / runner / archer | 28 / 24 / 26 / 22 |

| 分批参数 | 值 |
|---|---|
| 每批上限 | `clamp(ceil(total/4), 4, 10)` → 普通关**恒为 4 批**，`(批数-1)×0.85` = 3.4s 铺完 |
| 批间隔 | 0.85s（第一批 0s 立即出） |
| 批内错峰 | 每只 +0.12s，从画面外圈 `rad 330~510` 走现有 `spawnEnemy` 逻辑进入 |
| 同屏存活上限 | 22；>22 时下一批挂起，降到 16 以下再放（背压） |
| 首批朝向 | 至少 3 只从玩家**背向** 120° 内刷入，避免开局被包夹 |
| 精英批次 | 只落在第 1、2 批，不落最后一批（防清空后突然冒精英打断结算） |
## 3. 清空判定与结算时序（秒级）

| 阶段 | 时长 | 逻辑 |
|---|---|---|
| 最后一击 | — | `killEnemy` 后**不立即**结算 |
| ① 清空迟滞 | **0.60s** | `enemies.length===0` 起计时；期间出现任何**非召唤**新增敌（分裂子怪、宝箱怪）即清零回 combat；首领召唤物不计入 |
| ② 清场演出 | **1.68s** | 全屏去饱和 + 「通道开启」金字 + 金色上升粒子；任意 WASD/空格/E 可跳过（跳到演出末尾） |
| ③ 通道生长 | **0.90s** | 从地面锚点向上生长，**不可跳过**（形态见 §4） |
| ④ 可进入 | 无限 | 显示「踏入通道 [E]」，**必须按 E**。12s 防呆自动进入（`save.settings.autoPortal`，默认开）：计时器**在模态面板关闭后才起算**，任何输入重置、离开 46px 清零；面板关闭当帧即可按 E，无需先离开再进入。通道不关闭，可继续拾取 |
| ⑤ 海克斯三选一 | 玩家决策 | 仅 `n%3===0`；与 ④ **同帧**弹出、模态暂停，选完才能按 E |

**合计 3.18s**（不跳过 = 0.60+1.68+0.90）／**1.50s**（跳过演出），不含海克斯决策。首领关 ② 延长为 **3.20s**（慢动作+白闪+章节音效）→ 合计 **4.70s**。
**第 60 关顺序（唯一重合关）**：首领死 → 0.60s 迟滞 → 3.20s 演出 → 0.90s 通道 → 可进入 + 同帧弹海克斯。**增益在首领之后**，不能用来打首领。
**演出不与面板重叠**：海克斯面板只在 ② 结束后、④ 生效那一帧弹出；③ 生长期间不弹，避免全屏去饱和合成与模态面板糊在一起。
## 4. 通道机制

| 形态 | 适用章节 | 视觉 | 进入半径 | 进入演出 |
|---|---|---|---|---|
| 地下通道 `trapdoor` | 第 1–2 章（1–40） | 下沉石阶洞口，暖橙火光自下方溢出 | 46px | 0.45s 角色下沉 + 遮黑 0.20s |
| 石门 `stone_door` | 第 3–4 章（41–80） | 双扇巨人石门，缝隙渗出章节 accent 色光 | 46px | 0.50s 石门推开 + 灰尘粒子 |
| 裂境裂隙 `rift` | 第 5 章（81–100）＋ **章节首领关 20/40/60/80** | 空中撕开的紫色裂口，边缘符文溢出 | 46px | 0.60s 吸入 + 全屏白闪 0.12s |

**锚点**：地面接触点（底边中心），美术自锚点向上生长。**生成位置** = 最后一击坐标；若该点距玩家 <80px，先沿「玩家→该点」方向推到 120px 外，再 clamp 到 `x∈[160,1120]`、`y∈[170,600]`（W=1280 / H=720）；若与未使用 props 距离 <70 则沿 x 偏移 ±90。**进入**：锚点圆心距 ≤46px（沿用现有 props 手感）显示提示，必须按 `E`。**第 100 关不生成通道**：清场演出保留但金字改「裂境闭合」（无箭头/光圈/E 提示），3.20s 演出结束后直接 `endRun(true)`。
## 5. 关卡奖励结构

| 项 | 公式 / 值 |
|---|---|
| 击杀金币 | 普通 3–9（均值 6）／精英 45／首领 140；另 25% 概率掉金币包 5–18（均值 11.5） |
| 关卡结算金币 | `round(20 + 2.5n)` → n=5:32 / n=20:70 / n=50:145 / n=100:270 |
| 装备掉率 | 普通 6%／精英 48%／首领 95%（沿用现有 `dropChance`） |
| 关卡保底 | n≥5 起，通关时在通道旁生成「关卡宝箱」，必出 1 件（品质走现有 `makeEquipment` 的 `wave/600` 加成） |
| 首领关额外 | +2 件装备、+1 药水 |

| 采样关 | 总数 | 击杀金币期望 | 结算金币 | 本关合计 | 装备期望 |
|---|---|---|---|---|---|
| 5 | 8 | 149 | 32 | **181** | 2.3 |
| 20 | 7 | 196（首领） | 70 | **266** | 4.3 |
| 50 | 21 | 187 | 145 | **332** | 2.3 |
| 100 | 9 | 526（首领+8精英） | 270 | **796** | 5.8 |

**与现有经济对齐**：商店装备 120 金、铁匠 `60+2n`（n=50→160，n=100→260）、石像 30、药水 45。第 50 关单关 332 金 ≈ 2.8 件商店装备 或 2.1 次铁匠 —— 每关都买得起一件但必须取舍，不破坏现有金币稀缺感。
